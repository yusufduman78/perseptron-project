# notebooks

Bu klasör Jupyter/Kaggle notebooklarını içerir.

## Alt Klasörler

- `kaggle/`: Final deneylerin Kaggle üzerinde çalıştırıldığı notebooklar.
- `archive/`: Eski veya otomatik üretilmiş notebook kopyaları.

## Projedeki Rolü

Notebooklar, kodun sadece çalıştırılabilir hali değil; aynı zamanda deney sürecinin okunabilir anlatımıdır. Final Kaggle notebooklarında markdown açıklamalarıyla veri yükleme, embedding kullanımı, model eğitimi ve sonuç üretimi adım adım gösterilir.

## Raporla İlişkisi

Final raporda kullanılacak ana deneyler `notebooks/kaggle/` altındaki üç notebooktan gelir:

- Tabular-only
- Image-history
- Multimodal late fusion
